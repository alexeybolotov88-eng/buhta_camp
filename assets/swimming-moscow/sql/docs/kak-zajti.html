Вход администратора

Поле Значение Где лежит
Логин admin таблица admin_users
Пароль admin123 хеш SHA2(password, 256)
Роль супер-админ (is_super_admin = 1) роль admin
Email admin@swimmingmoscow.ru admin_users.email

Проверка в SQL: SELECT * FROM admin_users WHERE login='admin' AND password_hash = SHA2('admin123', 256);

Запуск БД

  1. 1
    Импорт скрипта
    mysql -u root -p swimming_moscow < swimming_moscow_schema.sql
  2. 2
    Открыть клиент
    TablePlus / DBeaver / phpMyAdmin / mysql CLI → база swimming_moscow
  3. 3
    Проверить админа
    таблица admin_users → login admin
  4. 4
    Сайт FAQ
    только опубликованные: VIEW v_faq_with_categories
FAQ: админка vs сайт

Что видит кто

Где Условие Что видно
Админка faq_items.is_active = 1 все вопросы, включая черновики
Сайт is_active = 1 и is_published = 1 только опубликованные
VIEW сайта v_faq_with_categories готовая выборка с категориями
Сиды сейчас 32 опубликовано · 1 черновик черновик — вечерний отчёт админа

Публикация: админ ставит is_published = 1 и published_at — вопрос появляется на сайте.
