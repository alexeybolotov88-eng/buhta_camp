2. Назначение

Этот документ — рабочая методичка по единому SQL-скрипту школы плавания Swimming Moscow. Скрипт создаёт таблицы, связи, индексы, начальные данные и представления. Отдельный сайт входа не требуется: доступ проверяется через MySQL-клиент (или будущую админ-панель, которая читает эти же таблицы).

Важно: пароли в сидах демо-уровня. Перед продом смените пароли и перейдите на bcrypt/argon2.

3. Как импортировать базу

  1. Установите MySQL или MariaDB.
  2. Создайте базу и выполните скрипт:
mysql -u root -p -e "CREATE DATABASE swimming_moscow
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

mysql -u root -p swimming_moscow < swimming_moscow_schema.sql

Порядок внутри скрипта: DROP → CREATE → ALTER → INSERT → VIEW. Скрипт можно запускать повторно (таблицы пересоздаются).

Для просмотра удобны TablePlus, DBeaver, phpMyAdmin или консоль mysql.

7. FAQ: админка и сайт

Сайт is_active = 1 и is_published = 1 только опубликованные

Категории в сидах: Обучение, Техподдержка, Расписание, Документы — по 8 опубликованных вопросов + 1 внутренний черновик.

Как опубликовать вопрос:

UPDATE faq_items
SET is_published = 1,
    published_at = NOW(),
    updated_by = 1
WHERE id = 33;

9. Полезные VIEW и запросы

-- FAQ для сайта
SELECT * FROM v_faq_with_categories
ORDER BY category_sort, is_pinned DESC, faq_sort;

-- Расписание конкретной недели
SELECT * FROM v_week_schedule
WHERE week_start = '2026-08-31'
   OR specific_date BETWEEN '2026-08-31' AND '2026-09-06'
ORDER BY specific_date, start_time;

-- Новые заявки
SELECT * FROM feedback
WHERE status = 'new' AND is_active = 1
ORDER BY created_at DESC;

10. Регламент администратора (кратко)

ВремяДействие
10:00Отчёт о готовности к работе (утро/дата)
до 12:00Проверка расписания, связь с пробниками вчерашнего дня
с 11:00Подтверждение визитов, оформление пробников, напоминания
12:00–15:00Работа с недошедшими, лист ожидания
до 18:00Напоминания новичкам на следующий день
22:00–23:00Вечерний отчёт: заявки, записи, пробные, сделки, выручка

SLA ответа: новым клиентам — до 10 минут, повторным — до 20 минут.

Оформление нового клиента: договор → правила абонемента → ссылка на оплату → таблица заполняемости → таблица оплат.

На занятие нужны: очки, шапочка, купальник/плавки, шлёпанцы, полотенце, анализ на энтеробиоз; для родителя — сменная обувь.
